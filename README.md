# Habit Mastery

Habit Mastery is an offline-first Flutter application for creating habits, recording daily progress, and reviewing activity history.

## Features

- Create and edit habits.
- Activate, pause, and delete habits.
- Record activity entries for individual habits.
- Review activity history and progress summaries.
- Store habits and activity entries locally using SQLite.
- Save user preferences using SharedPreferences.
- Use the application without an internet connection.

## Technology Stack

- Flutter and Dart
- SQLite with sqflite
- SharedPreferences
- Material Design
